# The Engineer's Daily

I'm exploring a simple daily practice.

Every day I:

- Read one engineering lesson.
- Build one small thing.
- Reflect on how it shapes me as an engineer and follower of Christ.

The goal isn't to learn faster.

The goal is to become wiser.

You're welcome to follow along.

## Setup

Install the project dependencies with `uv`:

```sh
uv sync
```

Run Harbor during Season 1 lessons:

```sh
uv run flask --app src.harbor run
```
